# Tuta absoluta RNA-seq Reanalysis

Reanalysis of public RNA-seq datasets related to insecticide resistance in Phthorimaea absoluta.

## Workflow

1. Download SRA files
2. FastQC / MultiQC
3. Trim Galore
4. Salmon quantification
5. Differential expression analysis (planned)
